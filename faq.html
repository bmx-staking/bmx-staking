FAQ

Quick answers about this BMX Staking prototype.

Is the 1B BMX real?

No. The 1,000,000,000 BMX starting balance is a simulation front-end balance stored locally in your browser.

Does staking send tokens?

No. The staking form updates the local preview state only. No blockchain transaction is signed.

Can another visitor see my balance?

Each visitor has their own browser-local state. The static site does not provide a shared private account database.

How do I make it production-ready?

Use a real token contract/program, wallet adapter, on-chain balance reads, secure backend services where needed, and an audited staking contract.
